# Factory presets

49 original starting points: Init plus six presets in each of eight categories. Select them in the native PRESET menu or desktop host program list. Every program recalls all 32 controls; no previous side/tube/AIR settings leak into the next program.

These are tonal starting points, not automatic repair, compression, de-essing or limiting. Mastering presets do not guarantee loudness or true-peak compliance. Begin with headroom, match bypass loudness with OUTPUT and listen in mono when widening. Width cannot create stereo from mono. Side cleanup uses bell filters, not a bass mono crossover. Tube colour changes with input level.

Original settings, inspired by [Universal Audio’s Pultec techniques](https://www.uaudio.com/blogs/ua/pultec-collection-tips-and-tricks) (interacting boost/attenuation and bus/instrument shaping) and [AIR Flavor Pro](https://www.airmusictech.com/effects/flavor-pro/) (parallel vintage colour and stereo width). No commercial preset files are copied; these are not emulations of those products.
